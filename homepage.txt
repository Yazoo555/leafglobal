2. CSS ARCHITECTURE & STYLING SYSTEM
===============================================================================

File: src/assets/css/main.css

The CSS is organized into three Tailwind layers:

  2.1 BASE LAYER (@layer base)
  ─────────────────────────────
  - HTML: smooth scrolling, antialiased fonts
  - Body: Inter font family, color: var(--color-text), bg: var(--color-background)
  - Headings: Inter font, weight 600, color: var(--color-dark)
  - Paragraphs: color: var(--color-text-light), line-height: 1.7
  - Links: color: var(--color-primary), transition on hover
  - Selection: blue background, white text

  2.2 COMPONENT LAYER (@layer components)
  ──────────────────────────────────────
  Contains all reusable CSS classes:

  Layout Classes:
    .container-custom     — mx-auto, max-w-7xl, responsive padding
    .section-padding      — py-16 sm:py-20 lg:py-24

  Gradient Classes:
    .gradient-subtle      — F8FAFC → F1F5F9 → E2E8F0 (hero background)
    .gradient-dark        — #0F172A → #1E293B (dark sections)
    .gradient-blue        — #2563EB → #60A5FA (technology/primary)
    .gradient-finance     — #047857 → #10B981 (finance/green)

7. ANIMATIONS & TRANSITIONS
===============================================================================

  7.1 v-scroll-reveal Directive
  ─────────────────────────────
  Usage:
    <div v-scroll-reveal>                        → fades in
    <div v-scroll-reveal="'slide-up'">           → slide-up animation
    <div v-scroll-reveal="{ animation: 'slide-up', delay: 200 }">
    <div v-scroll-reveal.stagger>                → staggered children

  Animation Types (Tailwind config):
    fade-in:      opacity 0 → 1 (0.6s)
    slide-up:     opacity 0 + translateY(30px) → visible (0.6s)
    slide-down:   opacity 0 + translateY(-10px) → visible (0.3s)
    scale-in:     opacity 0 + scale(0.95) → visible (0.4s)

  Behavior:
    - Uses IntersectionObserver
    - Respects prefers-reduced-motion
    - Triggers at 10% threshold, -60px root margin
    - Unobserves after first trigger


  7.2 Crystal Animations (CSS)
  ─────────────────────────────
  orbShimmer:      5s ease-in-out infinite — orb shimmer effect
  crystalShimmer:  7s ease-in-out infinite — card reflection sweep
  glassShimmer:    3s ease-in-out infinite — metallic shine effect

  Tailwind Animations:
    float:          6s ease-in-out infinite — vertical floating
    glow-pulse:     2s ease-in-out infinite — opacity pulse
    gradient-shift: 8s ease infinite — gradient background shift
    glass-shimmer:  3s ease-in-out infinite — glass shimmer sweep


  7.3 Page Transitions
  ─────────────────────
  Layout transition (DefaultLayout.vue):
    Duration: 0.25s
    Enter: opacity 0 → 1, translateY(10px) → 0
    Leave: opacity 1 → 0, translateY(0) → -10px


  7.4 Component Transitions
  ─────────────────────────
  Dropdown menus:
    Enter: 0.2s ease-out, opacity 0 → 1, translateY(2 → 0)
    Leave: 0.15s ease-in, opacity 1 → 0, translateY(0 → 2)

  Mobile menu:
    Enter: 0.3s ease-out, opacity + transform
    Leave: 0.25s ease-in

  Accordion menus:
    Enter: 0.25s ease-out, max-h 0 → 600px, opacity 0 → 1
    Leave: 0.2s ease-in, max-h 600px → 0

  Contact form success:
    Enter: 0.3s ease-out, opacity 0 → 1, scale 0.95 → 1
    Leave: 0.2s ease-in


  7.5 Hover Effects
  ──────────────────
  Glass cards:    translateY(-4px), darker shadow, bg increases
  Buttons:        scale 101% (hover), scale 98% (active)
  Nav links:      underline scale-x 0 → 1
  Social icons:   scale 110%, translateY(-2px), blue bg

10. CODE CONVENTIONS & BEST PRACTICES
===============================================================================

  10.1 Vue Component Structure
  ─────────────────────────────
  - Use <script setup> with Composition API
  - Define props with defaults and validators
  - Use computed properties for derived state
  - Use refs for reactive state
  - Clean up observers/listeners in onUnmounted

  10.2 CSS Organization
  ──────────────────────
  - Tailwind utilities for most styling
  - Custom CSS classes in @layer components
  - CSS variables for colors, shadows, radii, transitions
  - Avoid inline styles (except for dynamic values)

  10.3 Naming Conventions
  ───────────────────────
  - Components: PascalCase (Button.vue, Card.vue)
  - Files: kebab-case (scrollReveal.js, useAnimation.js)
  - CSS classes: kebab-case (glass-card, badge-blue)
  - Tailwind classes: utility-first approach

  10.4 Responsive Design
  ──────────────────────
  - Mobile-first approach
  - Use Tailwind responsive prefixes (sm:, md:, lg:)
  - Hide/show elements with hidden/block classes
  - Test at all breakpoints

  10.5 Accessibility
  ───────────────────
  - Use semantic HTML (header, main, footer, nav)
  - Add aria-labels to icon buttons
  - Support prefers-reduced-motion
  - Focus states on interactive elements
  - Proper heading hierarchy (h1 → h2 → h3)

  10.6 Performance
  ─────────────────
  - Lazy load images with loading="lazy"
  - Use IntersectionObserver for scroll animations
  - Debounce resize events
  - Use requestAnimationFrame for animations
  - Respect prefers-reduced-motion
