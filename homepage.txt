6. DESIGN PATTERNS & RECURRING ELEMENTS
   ---------------------------------------------------------------

   a) Glassmorphism Cards (.glass-card):
      - background: rgba(255,255,255,0.72)
      - backdrop-filter: blur(20px)
      - border: 1px solid rgba(255,255,255,0.5)
      - border-radius: 20px
      - Crystal top-edge highlight (::before)
      - Corner radial gradient shine (::after)
      - Hover: translateY(-4px), darker shadow

   b) Crystal Dividers:
      - Full-width horizontal line with centered orb
      - Line: gradient from transparent to chrome to transparent
      - Orb: 40px glass circle with inner dot + shimmer animation
      - Color variants: blue, green, orange, neutral
      - Light variant for dark backgrounds

   c) Color-Coded Sections:
      - Technology: blue (#2563EB) — badges, icons, borders, gradients
      - Finance:    green (#10B981) — badges, icons, borders, gradients
      - Education:  orange (#F97316) — badges, icons, borders, gradients

   d) Alternating Backgrounds:
      - white → background-secondary (#F1F5F9) → white → dark → white
      - Creates visual rhythm and section separation

   e) Section Pattern (Technology/Finance/Education):
      - 2-column grid with glass-card on one side
      - Badge + heading + description + bullet list + CTA button
      - Glass card with gradient icon + title + service grid

   f) Scroll Reveal Animations:
      - v-scroll-reveal directive on sections
      - v-scroll-reveal.stagger on grids for staggered entrance
      - Fade-in, slide-up, scale-in variants

8. RESPONSIVE BEHAVIOR
   ---------------------------------------------------------------
   Mobile (< 640px):
     - Single column layout throughout
     - Hero: text centered, right cards hidden
     - Trust indicators wrap
     - Testimonials: carousel with dots + arrows
     - Contact form: full width
     - Nav: hamburger → slide-out panel with accordion

   Tablet (640px - 1024px):
     - 2-column grids where applicable
     - Stats: 2-column grid
     - Nav: still hamburger

   Desktop (> 1024px):
     - Full 2-column or 4-column layouts
     - Hero: 2-column with floating cards
     - Nav: horizontal with dropdowns
     - Testimonials: 3-column grid
     - Contact: 3/5 + 2/5 split
