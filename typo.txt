1. FONT FAMILY
   ---------------------------------------------------------------
   The project uses a single font family throughout:
   "Inter" — a clean, modern sans-serif typeface.

   Fallback stack:
   Inter, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif

   Font configuration in tailwind.config.js:
     fontFamily.sans:   ['Inter', 'system-ui', '-apple-system', 'BlinkMacSystemFont', 'Segoe UI', 'sans-serif']
     fontFamily.heading: ['Inter', 'system-ui', '-apple-system', 'BlinkMacSystemFont', 'Segoe UI', 'sans-serif']

   Both sans and heading font families are identical — Inter is used
   everywhere for a unified, clean look.

   Loaded via Google Fonts with weights: 300, 400, 500, 600, 700, 800


2. FONT WEIGHTS USED
   ---------------------------------------------------------------
   weight-300: Light       — Used sparingly for subtle text
   weight-400: Regular     — Body text, paragraphs, descriptions
   weight-500: Medium      — Buttons, labels, badges, nav links
   weight-600: Semibold    — Headings (h1-h6), card titles, nav items
   weight-700: Bold        — Hero headings, stat numbers, section titles
   weight-800: ExtraBold   — Available but not heavily used


3. FONT SIZES
   ---------------------------------------------------------------
   Tailwind default sizes used:
     text-xs:    0.75rem   (12px) — Badges, subtexts, footer links
